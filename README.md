# Binomialverteilung · Übungen

15 Anwendungsaufgaben zur Binomialverteilung für den Mathe-LK Q2: Einstieg (genau k), kumuliert mit F, Abiturniveau.
Mit festem Rechner für P(X=k) und F(k), Histogramm je Aufgabe, Ergebnisprüfung und Musterlösungen.

Aufgaben stehen in `aufgaben.js`. Die Seite läuft ohne Build, braucht aber einen Webserver (ES-Modul):
`python3 -m http.server 8875`
